# Huckepack-Inhalte

Weitere Level für [Huckepack](https://github.com/Spectrechen/Huckepack), das Koop-Lernspiel für zwei Kinder auf zwei
iPads (Grundschule, Klasse 3, NRW). Jedes Paket bringt Level an bekannte Orte der Karte („Band 2“, „Band 3“ …).

*English: extra levels for Huckepack, a co-op learning game for two kids on two iPads. Content is German first.*

## Für Eltern
1. Lade die Datei `pack.json` eines Pakets aus `packs/` herunter (auf das Eltern-Gerät, z. B. in „Dateien“).
2. In Huckepack: Eltern-Bereich › Fächer › „Paket hinzufügen …“ › Datei wählen › Paket einschalten.
3. Beim nächsten Verbinden bekommen die Geräte der Kinder das Paket. Beide Kinder brauchen dieselben Pakete.

Huckepack lädt nichts selbst aus dem Internet; die Kinder-Geräte bekommen Pakete nur vom Eltern-Gerät, geprüft über
die signierten Eltern-Einstellungen.
